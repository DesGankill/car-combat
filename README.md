# Car Combat

Альфа машин с воксельным кузовом и серверной проверкой выстрела. Проект для практической работы №4: те же роли, что в Unreal, но на Unity.

Группа ИКБО-32-23: Мызников Роман Владиленович, Карамышева Виктория Сергеевна, Мелива Сергей Важаевич.

Движок: Unity 6000.5.10f1, Netcode for GameObjects 2.13.3. Сцена `Assets/Scenes/Arena.unity` собирается редакторным методом и уже должна лежать в проекте после первой генерации.

## Запуск двоих

1. Откройте папку `car-combat` в Unity 6000.5.10f1.
2. Откройте сцену `Assets/Scenes/Arena.unity` и нажмите Play.
3. Нажмите **Хост — listen server**. Это и сервер, и первый игрок.
4. Соберите клиент: File → Build Profiles → Windows → Build, папка `Builds`. Либо `Builds/CarCombat.exe`, если сборка уже сделана.
5. Запустите exe и нажмите **Клиент**. Адрес `127.0.0.1`, порт `7777`.

Оба окна должны оставаться в фоне: у игрока включён run in background.

## Управление

- WASD или стрелки — газ и руль.
- Q и E — башня.
- Пробел или левая кнопка мыши — выстрел.
- F1 — предсказание клиента. Без него машина ждёт позу сервера.
- F2 — сдвинуть свою машину только на этом компьютере. Следующая поза сервера возвращает её назад.
- F3 — выстрел, игнорируя местный кулдаун. Сервер такой выстрел не засчитывает, пока кулдаун не кончился.

Кнопки эмуляции на клиенте: `0 мс`, `100 мс`, `180 мс + 4%`. Задержка задаётся в одну сторону и добавляется и к команде, и к ответу сервера, поэтому от нажатия до движения без предсказания проходит примерно две таких задержки. Хост крутится локально, эмуляция на нём не включается.

## Что смотреть на защите

- Без предсказания и с задержкой 100 мс своя машина едет с опозданием.
- С предсказанием она едет сразу, а чужая машина только повторяет сервер.
- F2 или F3 показывает, что сервер не верит клиенту: позиция и кулдаун берутся с хоста.

# Базовый профиль репликации

Группа ИКБО-32-23: Мызников Роман Владиленович, Карамышева Виктория Сергеевна, Мелива Сергей Важаевич.

Практическая №5 просит снять трафик Unreal (`netprofile`, Network Profiler). В Car Combat слушающий сервер — Unity Netcode. Отдельного Network Profiler нет, поэтому замер считает байты того же канала, которым сервер рассылает объекты арены. Это исходящая полезная нагрузка на одного удалённого клиента, без своего хоста: хост объекты и так видит локально.

## Сцена

64 реплицируемых объекта, больше требуемых 50. Жанр — бой машин, поэтому это не деревья, а укрытие и угрозы:

| Тип | Сколько | Поведение в базовом замере |
| --- | ---: | --- |
| Серое укрытие | 40 | Стоит на месте, но всё равно уходит в каждом пакете |
| Зелёная подбивка | 12 | Стоит, пока её не забрали |
| Красный патруль | 12 | Ездит вокруг своей точки |

База нарочно без ограничений: каждый тик, 20 раз в секунду, все 64 объекта, всем клиентам. Запись объекта — номер, тип и пять `float` (x, z, рыскание, две скорости): 23 байта. Заголовок пакета — 7 байт.

## Условия

- Один удалённый клиент. Наблюдатель стоит в центре арены и смотрит на +Z. Так замер повторяется.
- Окно 5 секунд, 100 тиков.
- Две ближайшие подбивки забираются на тиках 20 и 60. В базе это ничего не меняет: их состояние и так шлётся всегда.

## Результат

| | Значение |
| --- | ---: |
| Объектов | 64 |
| Обновлений акторов | 6400 |
| Байт за 5 с | 147900 |
| Исходящий трафик | 28.89 КБ/с |

Тяжёлые здесь не патрули, а статичное укрытие: 40 из 64 объектов не меняются, но занимают 23 байта 20 раз в секунду. Это и есть избыточная репликация, которую дальше убираем.

Цифры считает `ReplicationBudget.Measure`. Та же строка видна в игровой панели. Проверка в редакторе не даёт этим байтам разъехаться с отчётом.
